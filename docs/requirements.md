# 要件定義書 — AI絵本デビュー完全ガイド（Instagramリール特典ページ）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）
- 操作者: ブラウザのエンドユーザー（Instagramリール視聴者）
- AI本体(プロンプトY): なし（ページはすべて静的。コンテンツは事前に決定し、静的テキストとして埋め込む）
- MCP: なし
- 自社DB: なし
- フロントUI: あり（このリポジトリそのものがフロントエンド全体）
- 動的変数: なし
- 種別: Web型（静的サイト。バックエンド・DB・ビルド工程なし）
- 配布: マイ専用（発信用GitHubアカウント mion-ai-mama 配下の個人リポジトリ）
- ホスティング: GitHub Pages（無料・静的ファイル配信のみ）
- 公開URL: https://mion-ai-mama.github.io/ai-ehon-debut-guide/
- 由来: `mion-ai-mama/instagram-tokuten-template`（特典ページテンプレート）を
  「Use this template」で複製して作成した、テンプレートの利用インスタンスの1つ。

## 1. プロジェクト概要

- 成果目標: Instagramリール「3児ママの限界夜活🌙 30分でAI絵本完成」の視聴者に配布する
  特典資料を、GitHub Pages上の1ページ完結型LP（ランディングページ）として提供する。
- 今回の特典タイトル: 「AI絵本デビュー完全ガイド」
  （ChatGPT・画像生成AI・Canva・Amazon KDPを使い、AI初心者でも絵本作りに挑戦できる4STEPガイド）
- 最終導線: 「AI絵本はAI活用のひとつ」→「AIを知ることと仕事に活かすことは別」→
  既存リードマグネット『AIマネタイズの教科書』のLINE登録へ、売り込み感を抑えて誘導する。

### 成功指標（定量）

- 特典ページ → 『AIマネタイズの教科書』LINE登録ボタンのクリック率
- リールのプロフィールリンク経由の特典ページ到達率
- ページ平均滞在時間（最後まで読了されるか）
- STEP1・STEP2のプロンプトコピー率（コピーボタン利用状況）

### 成功指標（定性）

- 「絵心も文才もいらない」を実感してもらえる、迷わせない4STEP構成
- 40〜50代・AI初心者でも読みやすいやさしい日本語、煽り表現なし
- 既存の発信世界観（3児ママの限界夜活）とページの世界観が地続きであること
- 競合特典の文章・構成・実例をそのまま流用しない、完全オリジナルの内容

## 2. 想定読者（ペルソナ）

- 40〜50代女性、AI初心者、ChatGPTは触ったことがあるが使いこなせていない
- 絵が描けない・文章を書くのが苦手、家事や仕事でまとまった時間が取りにくい
- 在宅でできる新しい働き方に興味があるが、専門用語や強い煽り表現には抵抗がある

## 4. データ設計概要

DBは使用しない。全コンテンツは `js/content.js` の `CONTENT` オブジェクトで一元管理し、
`js/script.js` がページ読み込み時にDOMへ反映する。`index.html` には初期値として
同内容を直接記述し、JavaScript無効時のフォールバック表示を担保する。

## 5. セキュリティ要件

- 個人情報の入力フォームなし、認証機能なし、決済機能なし → 該当するセキュリティ対策は最小限
- HTTPS: GitHub Pagesは標準でHTTPS配信
- 外部リンク（LINE誘導ボタン・Amazon KDP公式サイト）は `rel="noopener"` を付与

## 6. 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・ビルド工程なし）
- フォント: システムフォント（追加のWebフォント読み込みなし）
- ホスティング: GitHub Pages（`main` ブランチ / root）

## 7. 外部サービス一覧

| サービス | 用途 | 費用 |
|---|---|---|
| GitHub Pages | 静的サイトホスティング | 無料 |
| LINE公式アカウント | 『AIマネタイズの教科書』登録導線（既存の導線をそのまま利用） | 既存のため対象外 |

## 8. AI設計

該当なし（AI本体Yなし）。特典コンテンツ自体は著者が事前に作成した静的テキストであり、
ページ自体にAIのランタイム処理は含まれない。
